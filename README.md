# Angel Nguyen – Personal Portfolio & Professional Website

A modern, responsive personal portfolio and professional website showcasing coursework, technical skills, cybersecurity lab training, and work experience as an Information Systems &amp; Analytics student at Louisiana State University (LSU) and Security Operations Center (SOC) Analyst at the Louisiana Optical Network Infrastructure (LONI).

Built with semantic HTML5 and custom Vanilla CSS, utilizing a dark navy and charcoal design system accented with subtle glowing blue highlights and glassmorphic cards.

## Project Structure & Pages

- **`index.html` (Home Page)**:
  - **Hero & Background**: Professional dark navy/charcoal theme with active SOC analyst status and location.
  - **About Me**: Academic narrative focused on Information Systems &amp; Analytics with a Cyber Risk concentration.
  - **Work Experience**: Highlights current role as a SOC Analyst at the LSU LONI SOC.
  - **Selected Projects**: Showcases hands-on TryHackMe cybersecurity training with direct links to project details and profile.
  - **Technical & Analytical Skills**: Categorized skills covering security technologies (Splunk, CrowdStrike, Defender, Palo Alto, Cisco), programming/query languages (SPL, SQL, Python, Java), hardware/systems, and languages.
  - **Education & Certifications**: LSU B.S. program details, coursework, and TekStream Associate Security Analyst certification.
  - **Get In Touch**: Direct networking hub with Email, LinkedIn, and GitHub cards.

- **`project.html` (Project Deep-Dive)**:
  - Dedicated showcase for **TryHackMe Cybersecurity Labs &amp; Training**.
  - Detailed sections for Training Overview, Skills Practiced, Key Learnings, and TryHackMe profile verification.
  - Seamless navigation back to the home page and resume.

- **`resume.html` (Recruiter-Ready Resume)**:
  - Clean, recruiter-friendly digital resume structured into Education, Experience, Skills, Certifications, and Involvement.
  - Interactive top action bar and built-in print/PDF styling (`@media print`).

- **`styles.css` (Design System)**:
  - Unified color palette, responsive grids, custom typography (Plus Jakarta Sans &amp; JetBrains Mono), glassmorphic card effects, and accessibility considerations.
